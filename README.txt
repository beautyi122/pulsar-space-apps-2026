PULSAR / ORBITAL CLINIC — WEBSITE UPDATE
======================================

For the existing public repository:
https://github.com/beautyi122/pulsar-space-apps-2026

This update is a presentation layer over the ORIGINAL website. Do not delete or replace the existing scientific source files.

INSTALL (local repository checkout)
  1. Extract this ZIP.
  2. Run: python "Apply Design.py" /path/to/pulsar-space-apps-2026
  3. Review the updated website locally, including the recorded-data chart and new-data CSV analyzer.
  4. Commit only index.html, clinic.css and clinic.js from the updated repository.
  5. Verify GitHub Pages after deployment on desktop and mobile.

INSTALL (GitHub web editor, no Python)
  1. Upload clinic.css and clinic.js to the repository root.
  2. In index.html, add before </head>:
       <link rel="stylesheet" href="clinic.css">
  3. Immediately before </body>, after the existing app.js script, add:
       <script src="clinic.js"></script>
  4. Change meta color-scheme content from dark to light if present.
  5. Commit, then check the published site.

SCIENCE AND PRIVACY
  The original data.js, app.js, browser-signal.js and style.css are not replaced.
  The measured quantities, retrospective evaluation, limitation disclosures and scientific citations continue to come from the existing site.
  The comparison chart displays the actual stored window-level candidate frequency estimates; it does not show raw optical sample traces.
  No new server endpoint, tracker, analytics or collection/storage mechanism is added.
