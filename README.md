# Pulsar — Research demonstrator

**Team: Stella Nova**

An offline-capable web app for NASA Space Apps 2026. Open `index.html` or publish this repository with GitHub Pages, using the main branch at /(root).

This website replays previously examined terrestrial exercise sensor measurements and outer participant-held-out development decisions, not real-time astronaut data. Scientific evidence (332 windows across eight participants): 125 cautiously displayed, 3.62 bpm conditional MAE and 8 serious errors. No independent external clinical or spaceflight validation.

NASA exercise-reference source: [OCHMO-TB-031](https://www.nasa.gov/wp-content/uploads/2023/12/ochmo-tb-031-exercise-overview.pdf) p. 11. Terrestrial sensor dataset: [PhysioNet Wrist PPG During Exercise](https://physionet.org/content/wrist/1.0.0/), ODC-By 1.0.

The static GitHub Pages version does not support the separate local Python CSV inference service. That function is distributed in the full release for running locally.
